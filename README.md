# 플레이리스트

좋아하는 곡을 모아 두는 한 장짜리 웹페이지입니다.
왼쪽에 커버와 이름, 오른쪽에 트랙 목록이 놓이고, 곡을 누르면 바로 재생되면서 아래에 그 곡에 대한 코멘트가 나타납니다.

**→ https://아이디.github.io/저장소이름/**

---

## 무엇이 되나요

- 유튜브 주소만 넣으면 썸네일이 앨범아트로 자동 연결됩니다
- MP3 파일도 올려서 쓸 수 있습니다
- 곡이 끝나면 다음 곡으로 자동으로 넘어갑니다
- 재생·일시정지, 음량, 구간 이동이 되는 재생 바가 화면 아래에 붙습니다
- 곡마다 긴 코멘트를 달 수 있고, 굵게·기울임·밑줄·형광펜 같은 꾸미기가 됩니다
- 바탕색·글씨색·포인트 컬러를 마음대로 지정합니다
- 휴대폰에서는 세로로 알아서 다시 배치됩니다

---

## 파일 구성

```
index.html          ← 실제로 보여지는 페이지 (이것만 있으면 됩니다)
playlist-builder.html  ← 내용을 채워 index.html을 만들어 주는 편집 도구
music/              ← MP3를 쓸 경우 음악 파일을 넣는 폴더
```

`playlist-builder.html`은 내 컴퓨터에서 열어 쓰는 도구라 저장소에 올리지 않아도 됩니다.
커버 이미지와 앨범아트는 `index.html` 안에 그대로 담기므로 이미지 파일을 따로 올릴 필요가 없습니다.

---

## 만드는 방법 1 — 편집 도구 쓰기 (권장)

1. `playlist-builder.html`을 내려받아 브라우저로 엽니다
2. 왼쪽에서 커버, 이름, 색, 트랙을 채웁니다. 오른쪽에 결과가 바로 보입니다
3. 맨 아래 **HTML 코드 복사** 또는 **index.html 내려받기**
4. 그 파일을 저장소에 올립니다

## 만드는 방법 2 — 직접 고치기

`index.html`을 열면 중간쯤에 이런 부분이 있습니다. 여기만 고치면 됩니다.

```js
const PLAYLIST = {
  cover: "cover.jpg",      // 커버 이미지 경로
  zoom: 100,               // 확대 % (150이면 1.5배)
  x: 50,                   // 가로 위치 % (0 왼쪽 · 50 가운데 · 100 오른쪽)
  y: 50,                   // 세로 위치 %
  shadow: 24,              // 커버 그림자 진하기 (0이면 없음)

  eyebrow: "PLAYLIST",     // 맨 위 작은 머리말
  title:   "플레이리스트 이름",
  sub:     "작은 글씨 (페어명 등)",
  notesHead: "NOTES",      // 코멘트 위 머리말

  scrollAfter: 5,          // 이 수를 넘으면 목록만 스크롤 (0이면 전부 펼침)
  volume: 80,              // 처음 음량 (0~100)

  coverGlow: true,         // 커버 뒤에 커버를 연하게 깔기
  coverGlowOpacity: 16,    // 농도 %
  coverGlowBlur: 28,       // 흐림 px
  coverGlowSpread: 220,    // 범위 % (100이면 커버와 같은 크기)

  bgImage: "",             // 전체 바탕 이미지 (안 쓰면 비워두기)
  bgOpacity: 12,
  bgBlur: 0,

  tracks: [
    {
      title:  "곡 제목",
      artist: "가수",
      youtube: "https://youtu.be/영상주소",
      mp3: "",             // 유튜브 대신 파일을 쓸 때: "music/song.mp3"
      art: "",             // 비우면 유튜브 썸네일을 씁니다
      comment: "이 곡을 누르면 아래에 나타날 글"
    }
  ]
};
```

색은 파일 맨 위에서 바꿉니다.

```css
--bg:     #ffffff;   /* 바탕색 */
--text:   #111111;   /* 글씨색 */
--accent: #8a8a8a;   /* 포인트 컬러 */
```

어두운 바탕으로 바꿀 때는 바로 아래 `--line` · `--muted` · `--faint` 세 줄도 같이 바꿔야 목록 선이 묻히지 않습니다. 추천 값이 주석으로 적혀 있습니다.

## 코멘트 꾸미기

| 쓰는 법 | 결과 |
|---|---|
| `**글자**` | **굵게** |
| `*글자*` | *기울임* |
| `__글자__` | 밑줄 |
| `~~글자~~` | 취소선 |
| `==글자==` | 형광펜 (포인트 컬러) |
| `!!글자!!` | 강조색 (포인트 컬러) |
| 한 줄에 `---` | 가로줄 |

줄바꿈과 빈 줄은 적은 그대로 나옵니다.
편집 도구를 쓰면 글자를 끌어서 고른 뒤 버튼을 누르기만 하면 됩니다.

## 깃허브에 올리기

1. 새 저장소를 만듭니다 — **Public**이어야 무료로 공개됩니다
2. `Add file` → `Upload files`로 `index.html`을 올립니다
   (MP3를 쓴다면 `music` 폴더에 음악 파일도 같이)
3. `Settings` → 왼쪽 `Pages`
4. Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 두고 `Save`
5. 1분쯤 뒤 `https://아이디.github.io/저장소이름/` 으로 열립니다

저장소 이름을 `아이디.github.io`로 만들면 주소가 `https://아이디.github.io/` 로 짧아집니다. 계정당 하나만 됩니다.

곡을 추가할 때는 `index.html`을 새로 만들어 같은 자리에 덮어쓰고 커밋하면 자동으로 다시 배포됩니다.

## 알아두면 좋은 것

- **첫 곡 자동 재생은 안 됩니다.** 브라우저가 막습니다. 한 곡을 누른 뒤부터는 끝까지 알아서 이어집니다.
- **유튜브 썸네일이 안 뜨는 경우** — 비공개이거나 삭제된 영상입니다. 이때는 회색 칸으로 조용히 넘어가니 `art`에 직접 이미지를 넣으면 됩니다.
- **MP3 파일 크기** — 깃허브는 파일 하나당 100MB까지입니다. 곡이 많으면 저장소가 무거워지니 유튜브 쪽이 편합니다.
- 커버는 1000px 안쪽을 권합니다. 이미지가 파일 안에 담기기 때문에 너무 크면 `index.html`이 무거워집니다.
